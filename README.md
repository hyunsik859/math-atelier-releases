# 수학공방 업데이트

기존 수학공방 설치본이 새 버전을 받는 공개 배포 저장소입니다.

- [최신 릴리즈와 변경 안내](https://github.com/hyunsik859/math-atelier-releases/releases/latest)
- [업데이트 정보 latest.json](https://github.com/hyunsik859/math-atelier-releases/releases/latest/download/latest.json)

앱 왼쪽 아래 **새 버전으로 올리기**로 업데이트합니다. Releases의 ZIP은 기존 설치본에 적용하는 업데이트 파일입니다. 새 PC에는 별도의 전체 설치 묶음이 필요합니다.

업데이트 파일에는 화면 빌드와 앱 실행에 필요한 Python·JavaScript·AI 지시문이 포함됩니다. 계정 인증과 개인 시험 자료는 배포하지 않습니다.

앱 소스는 비공개 `math-atelier`, 최신 개발·운영 기록은 비공개 `math-atelier-records`에서 관리합니다. 공개 업데이트는 최신 3개와 필요한 설치·복구 예외를 보관합니다. 삭제한 구버전의 변경 안내·자산 목록은 기록 저장소에 남깁니다.
